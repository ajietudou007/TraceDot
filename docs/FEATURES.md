> 对应版本：**迹点点 V5.1.1**。所有功能默认本地运行，联网功能均需用户明确确认。
> 文档主体按模块分节撰写：01–06 为四大工坊与地图 / 珍藏册（早期编号沿用 V4 口径），
> 07 我的旅游计划与 08 年度报告为 V4.1 / V5 新增模块，V5 的关键变化集中在文末「V5 变更要点」。

## 00 · 外壳（Shell）

- **页签导航**：01 行程地图 / 02 我的旅游计划 / 03 火车票工坊 / 04 登机牌工坊 / 05 交通票工坊 / 06 影演票工坊 / 07 珍藏册 / 08 年度报告
- **侧栏交互**：磁吸聚光 · 扫光 · 流光边框 · 波纹涟漪（ReactBits 风格动效，仅 transform 动画）
- **主题**：青瓷绿主题色 + 明暗双主题；Aurora 漂移极光全站光场
- **模块架构**：各模块 HTML 经 Base64 解码注入隐藏 iframe 运行；`postMessage` 总线跨模块通信（独立消息标记 `__ticket` / `__plane` / `__transit` / `__venue` / `__collection` / `__ledger`）
- **数据总线**（V5.0.28 起）：`jddStore` 三层存储 —— 内存缓存（同步读）+ **IndexedDB 主存**（容量按浏览器配额，通常为数百 MB）+ localStorage 镜像（向后兼容）；两边都带写入时间戳，启动时谁新用谁；镜像超 1.1MB 只存轻索引（冷热分层）。回退开关 `jdd-store-mode = "ls"`
- **共享资源去重**：html2canvas、全球机场库 / 航司库、统一 UI 样式、动效脚本等 7 份资源跨模块只存一份（`shared-*` + `<!--jdd-shared:N-->` 占位还原）
- **响应式**：桌面 / 平板 / 手机（390px 级窄屏起）逐级断点，触屏目标 ≥44px
- **自适应性能模式**（V5.0.48）：`window.jddPerf` 采样帧时间并与屏幕刷新率折算的基准比较，弱显卡 / 软件渲染自动关掉大面积毛玻璃与装饰动画；拖拽缩放期间只暂停地图投影滤镜（`body.map-busy`），180ms 后恢复。桌面端主进程同步开启 `ignore-gpu-blocklist` 与 GPU 光栅化
- **激活码门禁**（V5.1.1）：首次打开需输入激活码，通过一次后本机记住、之后直接进入；未通过时应用整体不启动（原启动调用整体包在 `if (window.__JDD_BETA_OK__)` 内）。网页版与桌面版同一套门禁，校验在本机完成、不联网、不上传任何信息
- **液态玻璃导航**（V5.0.46 → 5.0.47）：右上胶囊改为四层玻璃（半透明渐变 + `blur(34px) saturate(200%)` + 上缘受光 / 下缘收光 + 静态镜面高光 + 14s 极慢流光，仅动 transform 走合成层）；选中项为透光绿玻璃珠

## 01 · 行程地图（Ledger）

- **自绘 SVG 中国底图**：无第三方地图库；完整全国视图（含台湾、南海诸岛附图），支持缩放平移、复位视图、图层控件
- **票面自动绘制**：
  - 火车 → 铁路实线弧 + 中点列车徽标
  - 航班 → 虚线航路 + 中段飞机标记（旋转对齐航向）
  - 公交 / 地铁 / 出租 / 客运 → 城市级点位
  - 电影 / 景区 / 演唱会 → 单地点票，退化为城市级单点标记
  - 演唱会星标 / 景区标记 / 公交地铁图标差异化标记
- **到访城市点亮**：柔光晕圈 + 实心点
- **地点解析四级兜底**：站名库（拼音反查）→ 机场库（IATA 码）→ 城市坐标库 → 模糊匹配（最长 key、口语站名兼容）；V4.0.2 起影城 / 景区 / 演出场馆优先实际 POI 坐标
- **榜单悬浮卡**：行程距离 / 总时长 / 总费用三张（V4.0.0），hover 抬升，移动端自适应
- **视图锁定**：整页不滚动，仅票面列表内部滚动；五步分区标题（等宽编号 + 点线 + 英文小标）
- **数据双保险**：localStorage 为主存储，IndexedDB `jdd-ledger` 镜像；localStorage 为空时从镜像恢复
- **顶栏动作**：导入 / 导出 / 添加行程（按钮位于珍藏册，经 postMessage 远程触发，导出带回执 toast）

## 02 · 火车票工坊（Ticket）

> 源自前身项目「12306 火车票票根编辑器」V6.2.x 内核。

- **六款票面底图**：蓝票 / 蓝纸票 / 蓝磁票 / 红票 / 红纸票 / 红磁票，正面与背面独立选用，全部内嵌离线可用
- **车票背面制作**：报销凭证「使用须知」模板，背景与遮罩自定义，正反面合并导出
- **模块级细节精修**：18 个票面模块（票号、检票口、站名、车次、二维码……）独立调整位置 / 字号（50%~200%）/ 字间距 / 粗细 / 字体（5 种内置 + TTF/WOFF/WOFF2 导入），按票种独立记忆
- **多选批量对齐**：多选后水平 / 底部 / 居左 / 居中 / 居右一键对齐；多行程同步渲染
- **12306 行程 PDF 智能导入**：拖入官方 PDF 自动解析回填；手动修改优先，空白不覆盖；「跳转官方下载」外链
- **纸质票拍照 OCR**：
  - 拍摄方向自动矫正（0°/90°/180°/270°）+ 透视矫正 + 标准票幅（85.6:54 → 1600×1009）裁剪
  - 本地引擎：PP-OCRv6（默认超精度）/ PP-OCRv5（高精度）/ Tesseract.js（轻量），纯本地推理、模型 IndexedDB 缓存后可离线
  - 联网引擎：Agnes 3.0 Flash（默认 AI 引擎，内置 Key）/ OCR.space / 百度 OCR——仅明确确认后上传，云端失败自动回退本地
  - 车厢 / 座位 / 检票口三级兜底补全；批量识别队列；CSV 导出（17 列，UTF-8 BOM）
- **智能联想**：站点 / 车次输入联想补全，站名拼音自动联动
- **导出**：单张 PNG 直下，多张自动打包 ZIP；文件名「车次_日期_站名」规范命名；触屏长按保存，兼容夸克 / UC 内核
- **数据**：多行程独立副本（深拷贝隔离）；LZ-String 压缩进 URL 分享链接；刷新逐程还原
- **珍藏册联动**：【导入珍藏册】写入航班 / 火车行程记录；被珍藏册编辑时按记录预填且不被本地草稿覆盖（V4.0.2）

## 03 · 登机牌工坊（Plane）

- **登机牌制作**：航班号、日期、到发机场 / 城市、舱位、登机口、座位、姓名（中英文）、电子票号等字段；Canvas 原生绘制
- **全球数据库联想**：内置全球机场库（IATA 码 + 坐标，2026-09-27 数据）与全球航司库（IATA 二字码，2026-09-28 数据），合并去重、内置优先
- **扫描件识别**：拖放 / 文件导入登机牌照片，Agnes AI 转录票面文字并匹配字段；每个字段带 BP-RE 置信度徽标与四维依据（悬停查看），低于阈值标黄「待人工核对」；导入失败常驻诊断框（可选中复制）
- **预览**：径向微光底 + 居中展示 + 暖色投影，与交通票工坊统一；动态柔和反射光（V3.3.9，仅预览装饰）；控制台「细节确认」区
- **导出**：html2canvas 离屏克隆 + 固定 2x 高清（倍数控件已移除）
- **珍藏册联动**：【导入珍藏册】写入航班行程记录（mode:'flight'）；被珍藏册编辑时机场三字码 / 中文机场名智能归位预填（V4.0.3）
- **草稿**：登机牌草稿与上传图本地保存（`bp-studio-draft`），「清除所有数据」一并清除

## 05 · 影演票工坊（Venue）

- **三票种**：电影票 / 景区门票 / 演唱会票
- **票面配色自定义**：主色 / 辅助色控件 + 实时预览；配色走 CSS 变量，按主色相对亮度自动派生文字与底色（浅色主题自动转深色文字）
- **图片区**：
  - 电影票：右侧海报区（OMDb 自动匹配——中文片名先经 Agnes 转英文，`?t=` 优先 `?s=` 兜底；仅电影票保留自动匹配）
  - 景区门票：票面下半部独立照片带（V3.1.9 下移）
  - 演唱会票：海报区
  - 全部带 8 段 smoothstep 渐隐遮罩（分界线隐形）；「海报待设置 / 景区图待设置」占位仅预览可见、导出隐藏
  - **自定义取景裁剪**（三票种通用，V3.1.12）：缩放 1.00×~3.00×、水平 / 垂直取景 0~100%、恢复默认；导出与预览逐像素一致；裁剪参数按票种独立保存
- **景区数据**：全国 5A / 4A 景区 5463 条模糊联想搜索（连续子串 + 子序列两级评分、5A 加权、「故博」命中「故宫博物院」）；所在城市 / 区县可手输 + 联动筛选（双向归一）
- **导出**：html2canvas 固定 2x，文件名 `venue-ticket-<票种>-<日期>.png`；票面总高：电影 273px / 景区 280px / 演唱会 250px
- **珍藏册联动**：【存入珍藏册】保留票种专用字段（影院 / 入口 / 人数等）便于再次编辑回填（V4.0.2）

## 06 · 珍藏册（Collection）

- **行程时间轴**：全部票面按出行时间串成编年史视图（标题「行程时间轴」+ 计数提示），票种筛选 chips（配色 / 图标随票种）与城市下拉筛选
- **顶栏工具**：【导入】【导出】【清除所有数据】【添加行程】右对齐（V3.1.14 自行程地图迁入）
- **一键清除所有数据**：危险样式 + 二次确认（列明清除范围并声明保留密钥）；清除 6 个用户内容键 + IndexedDB `jdd-ledger` 镜像；保留 OCR 密钥、主题、视图偏好等；清除后五 iframe 重载 + 就地刷新不闪屏
- **示例票面**：空态显示「导入示例文件」——9 票种各采集工坊预览框原始票面图（50% 展示、2x 高清像素、仅存当前会话内存），同步写入行程地图
- **展示方式**：单一「行程时间轴」视图——按出行时间正序串联每张票，无平铺 / 网格等其他展示方式（代码中保留了已隐藏的历史视图切换控件，仅时间轴对用户可见）
- **工坊直编**（V4.0.2~4.0.3）：卡片可直接跳转对应工坊编辑票面——火车 / 交通 / 影演 / 登机牌四工坊均支持按记录口径预填回填
- **导入 / 导出**：JSON 备份导入导出（导出带回执 toast）；V5.0.9 起另有 CSV / ICS 导出（在行程地图菜单）
- **通用备份解析**（V5.0.31）：认 V4 / 手机端导出的 `{ app, version, data:{ "trip-ledger.records.v1":"<JSON 字符串>" } }` 嵌套格式，逐层解字符串 → 认 records/data/任意键 → 兜底深扫
- **导入前快照 + 一键回滚**（V5.0.34）：导入前自动留档（留最近 5 份），回滚前再存一份「回滚前」，所以回滚本身也能撤销

## 通用约定

- **免责与合规**：各票面「纪念票样·非官方凭证」小字保留（电影票 / 景区门票 / 演唱会票票面水印已删）；仅供个人纪念与娱乐创作
- **自适应**：窄视口单列回退、触屏断点按钮 48px、iOS 聚焦防放大（输入 ≥16px）
- **测试基准**：Playwright 无截图断言；版本号全链一致（title + 徽标 + 注释口径）

## 07 · 我的旅游计划（Planner）

- **对话式 AI 行程规划**：输入一句话需求（如「杭州 2 日亲子游，住西湖附近，不要太赶」），七步实时进度 + 思考面板可视化
- **真实数据查询**：高德 JS API v2.0 查询地理编码 / POI / 天气（Key 用户自配，附五步申请教程）；未配置 Key 自动引导，接口不可用自动降级 AI 推荐
- **按天行程 + 时间轴双页签**（V5.0.36）：时间轴以 Day N 为节点、时刻为行；末尾另起一节「真实票据」，把与该城市相关的票据按日期排出来
- **行李清单**：随行程自动生成，支持多轮追问调整
- **容错**：AI 超时预算已调到够用（V5.0.3）；天数上限 `MAX_DAYS = 15`（V5.0.4，原来被硬编码砍到 7）；模型偶发输出非法 JSON 已加容错
- **不硬造数据**：计划数据里没有日历日期（只有 Day N + 时刻），所以不伪造日期、不假装「合并排序」

## V5 变更要点（V5.0.2 → V5.1.1，共 49 次迭代）

## 桌面端（Electron）

- **窗口**：1440×900，最小 960×640，`nodeIntegration: false` / `sandbox: true` / `contextIsolation: true`
- **外链**：`http(s)` 链接一律用系统浏览器打开，不在应用内导航
- **菜单**：帮助菜单含「检查更新…」「发布页（手动下载）」「切换性能模式」「项目主页」「官方网站」
- **自动更新**：`electron-updater` + GitHub Releases，启动 3 秒后静默检查；发现新版本先询问再下载；未签名 Mac 包自动降级为打开发布页
- **渲染兜底**：`ignore-gpu-blocklist` / `enable-gpu-rasterization`；把 `displayFrequency` 注入渲染进程供性能判定使用；`show: false` + `ready-to-show`；`v8CacheOptions: 'code'`
- **构建**：`npm run dist:win`（NSIS x64）/ `npm run dist:mac`（dmg + zip，arm64 / x64）；CI 打 `v*` 标签自动构建 Windows 安装包

## 通用约定
