Local first · cloud optional

数据默认在你手里，
云端只是可选项。

迹点点默认把票根存在本机：不登录也能完整制票、整理与导出。 登录之后才会出现云端能力——昵称头像同步、加密备份与跨设备恢复。 每一步都由你主动触发，没有任何后台自动上传。

这几种情况，数据才会离开本机

  • 你点「备份到云端」：只上传加密后的备份包，明文票根不会离开设备。
  • 你登录账号：只同步昵称与头像，不会自动上传票根。
  • 你主动使用联网功能：AI 识图、海报查询、AI 行程规划与铁路查询会发出查询请求。
  • 你主动删除云端备份：服务端副本一并删除，本机票根不受影响。

以上都不使用也可以一直离线：断网时制票、筛选与导出照常可用。

01
本地优先

网页端把票根存在浏览器的 IndexedDB 并做一份 localStorage 镜像；安卓端存在应用私有数据库。断网也能制票、翻珍藏册和导出。

02
账号只负责身份，不接管数据

登录后可同步昵称与头像，换设备看到的是同一个你。账号本身不保存票根，也不会因为退出登录而清空本机内容。

03
零知识加密备份

备份在本机 gzip 压缩后用 AES-GCM 加密，密钥由账号密码经 PBKDF2（21 万次迭代）派生；服务端只保存密文，看不到密码、密钥和票面内容，最多保留 3 个版本。

04
跨设备恢复与随时退出

新设备用密码解密恢复；忘记密码可用申请时生成的恢复码。恢复时云端较新的记录覆盖本地同名记录，本地独有记录保留；云端删除后同步删除。不备份、不登录都能正常使用。

密码不上传

登录与备份都用派生密钥完成，明文密码不会写进任何请求。

服务端只见密文

备份包在设备上完成加密，服务器只负责存储与版本管理。

随时可删

删除云端备份会连同服务端副本一起清除，本机票根继续保留。

License · update · messages

激活、更新与通知，
规则写在明面上

客户端不是装完就失联。授权状态、版本门槛与官方通知都由云端统一管理，出现问题时也知道该去哪里看。

激活码在云端校验

激活码与账号绑定，在云端校验状态；后台可以停用、吊销或延期。网络异常时保留上一次的已激活状态，不会因为一次断网把人挡在门外。

授权 · 停用 / 吊销 / 延期
强制更新门禁

应用读取发布清单判断版本；低于最低支持版本时必须升级后才能继续使用。覆盖安装保留本机票根，更新失败会保留上一次确认结果，不会误放行。

macOS 首次打开提示「无法验证开发者」

  1. macOS 桌面包未签名、未公证，这是 Gatekeeper 的正常提示，不是文件损坏。
  2. 把「迹点点」拖进「应用程序」，首次打开时若被拦截，进入 系统设置 → 隐私与安全性，在底部点「仍要打开」。
  3. 也可以在 Finder 中右键应用 →「打开」，再确认一次；之后就能正常双击启动。
  4. 不放心可以先看源码并自行构建，或改用网页端。

安装与数据须知

  1. Windows 安装版带卸载入口；便携版解压即用，配置留在解压目录。
  2. 同渠道覆盖安装不会清空本机票根；V6 内测包为独立签名，需按申请页说明安装。
  3. 网页端与桌面端各自保存在本机，换端时用账号的加密备份恢复即可。
  4. 所有版本都不包含广告、统计 SDK 与后台静默上传。
