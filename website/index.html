ARCHITECTURE & PRIVACY

你的数据，只属于你的浏览器

迹点点所有数据逻辑均在前端运行：无后台用户数据库、无账户绑定、无追踪。断网环境下所有制票与时间轴整理功能均可离线运行。

01

原生单文件，零构建负担

原生 HTML / CSS / JS，无需安装环境，双击即可直接在任何现代浏览器中运行。

02

localStorage + IndexedDB 镜像

本地双保险备份，即便清除单个键也不会轻易丢失行程记录，支持 JSON 导入导出与快照。

03

本地多引擎 OCR 与 AI 转录

内置 PP-OCRv6 与 Tesseract.js 本地离线引擎，亦可按需使用多模态大模型一键提取纸质票面。
