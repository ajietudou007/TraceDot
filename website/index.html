32 套纪念票面进工坊 新增

公交 / 地铁 / 出租 / 船票 / 客运与电影 / 演唱会 / 景区各 4 套，内置真二维码与条码，换色跟随城市。

地图站名缩放修复 回归修复

缩放补偿误用 CSS transform，放大后站名变巨型文字；改用 SVG transform 修复。

年度报告 第 8 视图

年度大数字、12 格月度热力、单程榜单与准点率一次看完，按月时间轴合并在报告内。

票面码制做真 PDF417 / Code128

登机牌改用真 PDF417 + BCBP；火车票二维码指向这张票自己的车次与票号，不再一律跳 12306 首页。

粘贴即录入

把 12306 短信或订单邮件正文整段贴进工坊即自动填票，支持多种区间写法与订单号识别。

数据不再悄悄丢 IndexedDB

账本迁入 IndexedDB 主存 + localStorage 镜像，不再撞 5MB 墙；导入前自动快照，回滚可撤销。

老备份导得进来

备份解析器认得 V4 与手机端旧结构，老用户不再被「格式不支持」挡在门外，草稿自动迁移。

安全评审与加固

修掉一处可被恶意备份触发的存储型 XSS，补上导入体积与条数上限，联网识别时明确提示照片将上传。

ARCHITECTURE & PRIVACY

你的数据，只属于你的浏览器

迹点点所有数据逻辑均在前端运行：无后台用户数据库、无账户绑定、无追踪。断网环境下所有制票与时间轴整理功能均可离线运行。

01
原生单文件，零构建负担

原生 HTML / CSS / JS，无需安装环境，双击即可直接在任何现代浏览器中运行。

02
IndexedDB 主存 + localStorage 镜像

V5 起账本以 IndexedDB 为主存、localStorage 为镜像，并用写入时间戳仲裁新旧；导出前的自动快照与一键回滚让误导入不再是单向操作。

03
本地多引擎 OCR 与 AI 转录

内置 PP-OCRv6 与 Tesseract.js 本地离线引擎，亦可按需使用多模态大模型一键提取纸质票面；V5 起选择联网引擎会明确提示照片将上传。

04
V5 安全评审与加固

修复一处可由恶意备份触发的存储型 XSS，加入导入体积与条数上限、三条低风险 CSP 指令，制票与时间轴整理依旧全程离线。

* 仅在联网查询海报或选择云端 AI 时经由用户授权发起安全请求
