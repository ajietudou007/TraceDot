WHY TRACEDOT

把细节做得像真的，
把使用做得很轻。

九种票面、地图、OCR、海报匹配和本地存储，都是为了让你更快回到那一次出发。

01 / ONE STUDIO

九种票面，一站式制作。

明暗双主题、移动端自适应，所有票面以真实票样为参照设计。旅行从一张票开始，也可以在一张票里被重新打开。

02 / MAP

行程地图自动绘制

站名、机场、城市与景区多级地点解析，失败时自动回退到城市级单点标记。

03 / AI

AI 能力开箱即用

视觉大模型转录票面文字，OMDb 自动匹配电影海报，少一点手填。

04 / OCR

本地 OCR 多引擎

PP-OCRv6、Tesseract.js 与联网备选引擎，按你的需求选择识别方式。

05 / LOCAL

数据本地双保险

localStorage + IndexedDB 镜像，断网可用，数据始终留在自己的设备。

BUILT QUIETLY

你的数据，
只属于你的浏览器。

迹点点把复杂的事情放在前端完成：无账号、无追踪、无后端档案。你决定什么时候联网，数据就留在哪里。

01

原生 HTML / CSS / JavaScript

无框架、无构建步骤、无运行时依赖。单文件多模块结构，双击即可打开。

02

postMessage 总线通信

外壳与六个功能模块通过独立消息标记通信，共享资源去重存储。

03

导出管线与自绘地图

html2canvas 1.4.1 负责高清票面导出，铁路和航班路线由 SVG 贝塞尔曲线绘制。

数据不出浏览器

PRIVATE BY DEFAULT
票据、表单与导出图片默认只保存在本机。
localStorage + IndexedDB 双保险，断网也可用。
清除数据只影响用户内容，设置与密钥保留。
只有两类操作会在你明确确认后联网：OCR 联网引擎上传票面照片，以及影演票工坊向 OMDb 请求电影海报。
