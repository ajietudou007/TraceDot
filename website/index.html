V5.1.5 · WHAT'S NEW

第五个大版本：把「看起来像」补齐成「真的是」

票面上的码可以真被扫出来，数据不再悄悄丢失，年底还能回头看一整年的足迹。V5 阶段共端上 53 次迭代，每一条都写进了更新日志。

放大后站名变巨大修复

V5.1.5 修复

地图标记的缩放补偿误用了 CSS transform —— CSS 的 translate() 必须带单位，无单位写法会被浏览器静默丢弃，放大后机场 / 火车站名跟着地图一起变成巨型文字。改用 SVG 原生 transform 后尺寸恒定；桌面端内容热更新补上无边框进度窗与任务栏进度。

年度报告

第 8 视图

年度大数字、12 格月度热力、单程榜单与准点率一次看完；按月的「这一年」时间轴合并在报告里，不再往导航里塞第 9 个标签。

票面码制做真

PDF417 / Code128

登机牌条纹改用真票面码制 PDF417 + BCBP；火车票二维码不再统统指向 12306 首页，而是这张票自己的车次、日期、区间与票号；交通票与影演票启用 bwip 真条码渲染。

粘贴即录入

把 12306 短信或订单邮件正文整段贴进火车票工坊即可自动填票面，支持无年份日期、「-/至/→」多种区间写法与订单号识别。

数据不再悄悄丢

IndexedDB

账本迁入 IndexedDB 主存 + localStorage 镜像并引入写入时间戳仲裁，不再撞 5MB 墙；每次导入前自动留快照，菜单里一键回滚，且回滚本身还能撤销。

老备份导得进来

通用备份解析器认得 V4 与手机端导出的旧结构，老用户不再被一句「格式不支持」挡在门外；旧票面草稿自动迁移到新表单。

安全评审与加固

修掉一处可被恶意备份触发的存储型 XSS，补上导入体积与条数上限、CSP 三条低风险指令，并在使用联网识别引擎时明确提示照片将上传。

ARCHITECTURE & PRIVACY

你的数据，只属于你的浏览器

迹点点所有数据逻辑均在前端运行：无后台用户数据库、无账户绑定、无追踪。断网环境下所有制票与时间轴整理功能均可离线运行。

01

原生单文件，零构建负担

原生 HTML / CSS / JS，无需安装环境，双击即可直接在任何现代浏览器中运行。

02

IndexedDB 主存 + localStorage 镜像

V5 起账本以 IndexedDB 为主存、localStorage 为镜像，并用写入时间戳仲裁新旧；导出前的自动快照与一键回滚让误导入不再是单向操作。

03

本地多引擎 OCR 与 AI 转录

内置 PP-OCRv6 与 Tesseract.js 本地离线引擎，亦可按需使用多模态大模型一键提取纸质票面；V5 起选择联网引擎会明确提示照片将上传。

04

V5 安全评审与加固

修复一处可由恶意备份触发的存储型 XSS，加入导入体积与条数上限、三条低风险 CSP 指令，制票与时间轴整理依旧全程离线。
