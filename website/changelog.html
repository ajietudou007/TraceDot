V5.1.5 最新稳定版 回归修复
calendar_today 2026-10-22
zoom_out_map 放大后站名不再爆大

缩放补偿写成了 CSS transform，而 CSS 的 translate() 必须带单位 —— 无单位写法属于无效声明，会被浏览器静默丢弃，于是整组补偿从未生效：放大时城市圆点、站点圆点、站名一起跟着地图放大。改用 SVG 原生 transform 属性后，放大 21.9 倍站名仍 15 px、圆点仍 5.7 px。

download 内容更新看得到进度

桌面端内容热更新只换约 12 MB 的 HTML，原来从点「下载」到「重启生效」中间毫无反馈，慢网下像卡死。现在有无边框进度窗（进度条 + 百分比 + 已下载 / 总大小），进度同步到任务栏 / Dock 图标；壳安装包更新也复用同一个进度窗。

详细修补条目 (Bug Fixes & Refinements)
check_circle 巨型文字回归已修：站名、城市名、站点圆点的缩放补偿改用 SVG 原生 transform 属性，放大到 21.9 倍屏幕上尺寸仍恒定。
check_circle 下载进度可感知：内容更新与壳更新都显示进度条、百分比与已下载 / 总大小；任务栏 / Dock 图标同步进度，完成或失败自动关闭并清空进度。
check_circle 下载器两处隐患：重定向的 Location 为相对路径时不再抛 Invalid URL；跟随重定向前先等旧流关闭并清理半成品，不再出现 rename 报 ENOENT。

location_on 城市不再点错省

城市匹配原来是子串判断，昆山南 会命中西藏「山南」、大兴 命中「大兴安岭」。现在改为前缀锚定，并新增构建期「站点 → 城市」显式映射表 3267 站（由 12306 所属城市 + 底图市级轮廓判定生成），运行时 O(1) 查表，跨省误配彻底消失。

V5.0.48 性能优化 · 弱显卡适配
calendar_today 2026-10-21
bolt 自适应性能模式

在 Intel 核显的 Mac 上「特别卡」的机型，现在会自己降级：启动后采样 90 帧，拿 实测帧时间对比屏幕刷新率折算的标准帧长，p75 超过 1.75 倍且高于 22ms、或长帧占比过三分之一，连续两轮命中才切性能模式；命中 WebGL 软件渲染（SwiftShader / 基础渲染驱动）则直接切。降级只动大面积滤镜与装饰动画——整窗 blur(80px) 光晕、26–34px 毛玻璃收到 8–10px、logo 三层 240px 投影收成一层、导航流光与地图循环动画暂停——不改布局、不改配色。

jddPerf Auto Eco
layers 拖拽缩放不再掉帧

地图的投影滤镜挂在 .g-land 整组上，而组里还有无限循环的线路动画 —— 等于缩放时整块 1100×800 的 drop-shadow 每帧重算。现在 viewBox 连续变化期间只关滤镜（不隐藏任何图层，阴影色块不会中途消失），停顿 180ms 后自动恢复，静态观感不变。
