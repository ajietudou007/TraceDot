V4.1.2当前版本

2026-10-06
  • 手机端新增「添加票面」与「我的」两页，底部标签栏由 7 个精简为 5 个（行程地图 / 我的旅游计划 / 添加票面 / 珍藏册 / 我的）——四个票务工坊移出底栏，统一从「添加票面」进入（页内以卡片选择火车票 / 登机牌 / 交通票据 / 影演票据工坊，配悬浮返回钮回本页）；「我的」页含用户头像与改名、数据管理（导出 / 导入 / 云端更新 / 清除行程数据）、通用（软件更新 / 联系方式）与关于（版本信息 / 开发者 / 致谢 / 鸣谢 / 赞助商 / 数据使用与隐私声明）
  • 手机端统一设计语言注入层（顶部栏 / 对齐网格 / 卡片面板 / 表单输入 / 按钮 / 小标签与图标按钮）——仅在「移动端 UA + 视口 ≤640px」双条件同时成立时启用，桌面端与宽屏完全不受影响
  • 修复：交通票据 / 影演票据工坊「色彩自定义」色卡形状畸变——统一设计语言的小标签规则误把票面色卡当作文字标签处理，padding:0 14px 在 border-box 下把内层渐变块（width/height:100% + border-radius:50%）压成约 10×38 的竖长椭圆；现将 .face-chip 移出该规则组，色卡恢复 40×40 正圆（内层 36×36）
  • 修复：手机端登机牌工坊整页无法上下滑动、制作台表单下半部分滑不到——模块自带主题响应层把 .tab-body 改为 overflow:visible，而根部视口锁（height:100dvh + overflow:hidden）又把布局高度压到视口剩余值，导致表单底部约 248px 被裁且无任何可滚处；现于手机端解除视口锁、内容按自然高度排布，恢复自由滑动
  • 修复：手机端火车票工坊滑到中段卡住、顶部栏不吸顶——模块根部 html,body 同时为 overflow:auto 的 flex 列容器，body 成为「不会滚动的滚动容器」（吸顶失效）且 WebKit 无法在两层滚动容器间接力手势；现手机端让文档回到标准块级滚动（html 唯一滚动器、body 普通块级），并放开 .scroll-area 的 overscroll-behavior:contain
  • 修复：手机端行程地图三处问题——南海诸岛附图未放大时显示不完整（preserveAspectRatio 由 slice 恢复 meet 并上移）、全屏按钮被地图 SVG 覆盖导致点击无反应且无法退出放大（提升标题行 z-index）、放大态标题重影（隐藏 hero 区并改不透明卡片背景）
  • 修复：手机端「我的」页「软件更新」点击无有效反馈——更新弹窗外被外壳「点击空白处关闭弹窗」监听器立即关闭（补 stopPropagation）；版本比对改为只比较数字版本号，此前两侧文案带「当前 / 最新」前缀恒不相等，「已是最新」分支永不可达且会误开弹窗
  • 版本号全链同步 V4.1.2（文件名 / title / 品牌徽标 / 版本弹窗两枚标签 / 关于页 / 导出备份元数据）；桌面端应用同步升级至 V4.1.2（Electron 打包，Mac arm64/x64 dmg+zip、Windows x64 NSIS 安装包）
